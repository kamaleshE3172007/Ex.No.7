# EXPLANATION

Prompt engineering is the process of designing effective instructions or prompts for an AI model to obtain accurate, relevant, and useful responses.

Instead of giving a simple prompt such as:

> "Write a project report."

a more effective prompt provides the **role, task, context, requirements, format, and expected output**.

### Example

Basic Prompt:

> Write a report about Artificial Intelligence.

Improved Prompt:

> Act as a technical writer. Prepare a 500-word technical report on Artificial Intelligence in Healthcare for undergraduate engineering students. Include an introduction, applications, benefits, limitations, and conclusion. Use simple technical language, maintain a formal tone, and avoid unsupported claims.

The second prompt provides more context and therefore produces a more targeted response.

# 1. TECHNICAL REPORT

### Initial Prompt

> Write a technical report about Artificial Intelligence in Healthcare.

### Improved Prompt

> Act as a technical writer. Create a formal technical report on "AI-Assisted Healthcare". Include Introduction, Problem Statement, Existing System, Proposed AI Solution, Applications, Advantages, Limitations, Future Scope, and Conclusion. Write for undergraduate engineering students using clear and technically accurate language.

### Iterative Improvement Prompt

> Improve the previous report by correcting grammar, removing repetition, improving technical accuracy, and making the content more readable without changing the main ideas.

# 2. RESEARCH ABSTRACT

### Prompt

> Write a research abstract on AI-assisted healthcare systems. Include the problem, proposed approach, methodology, expected outcome, and significance. Keep it within 200–250 words and use formal academic language.

### Iterative Prompt

> Rewrite the abstract to make it concise, technically accurate, and suitable for an academic research paper. Remove unnecessary statements and avoid unsupported claims.

---

# 3. LITERATURE REVIEW

### Prompt

> Create a literature review structure for research on AI-based healthcare systems. Organize it according to existing approaches, technologies used, advantages, limitations, research gaps, and future opportunities. Use an academic writing style.

### Iterative Prompt

> Improve the literature review by creating a logical flow between studies, identifying research gaps clearly, reducing repetition, and distinguishing established findings from proposed ideas.

**Note:** AI-generated references must be independently verified before being included in an actual research paper.

# 4. PROJECT PROPOSAL

### Prompt

> Act as a project proposal writer. Prepare a project proposal for an AI-based healthcare assistance system. Include title, background, problem statement, objectives, proposed methodology, technologies, expected outcomes, advantages, limitations, timeline, and future scope.

### Iterative Prompt

> Improve the proposal by making the objectives measurable, the methodology technically realistic, and the expected outcomes clearly defined.

# 5. RESUME

### Prompt

> Act as a professional resume writer. Create a one-page resume for a computer science engineering student applying for a software development internship. Include career objective, education, technical skills, projects, certifications, achievements, and soft skills. Use ATS-friendly formatting and concise professional language.

### Iterative Prompt

> Improve the resume for an entry-level software developer position. Use strong action verbs, remove unnecessary information, quantify achievements where evidence is available, and ensure the content remains truthful.

### Prompt

# PROMPT-BASED APPLICATION

## Personal Productivity Assistant

### Main Prompt

> "Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user’s changing preferences over time."

---

# FEATURES

### 1. Daily Task Manager

The assistant can:

* Accept tasks using natural language.
* Organize tasks based on priority.
* Track deadlines.
* Display pending tasks.
* Generate daily task summaries.

**Example:**

> User: I need to complete my project report by tomorrow.

**Assistant:**

> Task added: Complete project report
> Priority: High
> Deadline: Tomorrow

---

### 2. Smart Scheduler

The assistant can:

* Understand natural-language scheduling requests.
* Organize appointments.
* Identify possible scheduling conflicts.
* Suggest available time slots.

**Example:**

> User: Remind me to study Java at 7 PM.

**Assistant:**

> Study Java – 7:00 PM reminder added.

---

### 3. Wellness Tips Generator

The assistant can provide general productivity and wellness suggestions such as:

* Taking short breaks
* Staying hydrated
* Maintaining a study schedule
* Reducing excessive screen time
* Including physical activity in a daily routine

---

### 4. General Query Assistant

The system can answer general questions and assist with:

* Academic tasks
* Programming questions
* Project planning
* Writing
* Study planning

---

# PROCEDURE

### Step 1: Define Requirements

Identify the major requirements of the personal productivity assistant:

* Task management
* Scheduling
* Reminders
* General queries
* Preference adaptation

### Step 2: Create Initial Prompt

Develop a simple prompt describing the application and its required features.

### Step 3: Improve the Prompt

Add:

* Role
* Context
* Specific requirements
* Output format
* Constraints
* Examples

### Step 4: Generate Output

Submit the prompt to an LLM such as ChatGPT and analyze the generated response.

### Step 5: Iterative Prompting

Improve the output by providing additional instructions.

Example:

> Improve the previous response by making it more concise, organizing tasks according to priority, and presenting the result in a table.

### Step 6: Test the Application

Provide different user inputs and verify whether the assistant generates appropriate responses.

### Step 7: Evaluate the Output

Evaluate the generated content based on:

* Grammar
* Technical accuracy
* Plagiarism/originality
* Readability
* Relevance
* Completeness

# ITERATIVE PROMPTING

Iterative prompting means repeatedly improving an AI-generated response through additional instructions.

### Initial Output

> Write a project proposal for an AI healthcare system.

### Iteration 1

> Add objectives, methodology, technologies, and expected outcomes.

### Iteration 2

> Make the methodology technically realistic and suitable for an undergraduate project.

### Iteration 3

> Improve grammar, remove repetition, and make the proposal more concise.

### Iteration 4

> Check the technical claims and identify statements that require verification.

This process improves the quality of the final output.
